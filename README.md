# Rainy 's Choas Events Minigame!!!

a chaos events mod built for messing around with your friends and losing your mind every 30 seconds.

Hehehe , every 30 seconds something will happen to you :) , or yoour friends , OR BOTH OF YOU!
Forget the normal peacful aaah survival mc where we finish the game in 4h speed run
## /choas start
 It starts the minigame where it involves the players who joined and apply the events on them
 
To be in the game you need to DO /choas Join
To leave you can do /choas leave

To Stop the game itself do /choas stop
